# Медиастанция

`oc2r:media_station` объединяет дисковод и программатор в одном блоке.
Медиастанция — единственный блок для этих задач. ID, предметы, рецепты
и таблицы добычи старых `disk_drive` и `flash_memory_flasher` удалены.
Старые блоки в сохранённых мирах не сохраняются. Рецепт медиастанции использует
железо, плату, красную пыль, компаратор и интерфейс шины.

У станции два независимых гнезда:

- Верхнее — дискета. Вставка предметом в руке; Shift + ПКМ по верхней
  половине блока извлекает дискету.
- Нижнее — флеш-память или HDD. Вставка соответствующим предметом;
  Shift + ПКМ по нижней половине извлекает носитель.
- Обычный ПКМ открывает существующее окно записи прошивки/образа.

Предметный обработчик имеет два слота: 0 — дискета, 1 — флеш/HDD.
На задней стороне один стандартный порт шины. Компьютер получает через
него два отдельных устройства VirtIO block; драйверы гостевой ОС прежние.
Данные и компоненты обоих носителей сохраняются независимо.

Запись прошивки эксклюзивно блокирует нижний слот. Пока носитель подключён
к запущенной VM, локальная запись не начинается. Верхний слот независим.
При разрушении блока оба носителя выпадают один раз с сохранёнными данными,
в том числе если в этот момент шла запись прошивки.

## Проверки

Серверные случаи находятся в `MediaStationTests`: типизация обоих слотов,
HDD, два устройства на одной шине, сохранение/загрузка, независимое извлечение
и разрушение во время записи.

Воспроизводимый клиентский прогон проверяет отображение вставленной дискеты,
синхронизацию обоих носителей и открытие окна программатора:

```sh
JAVA_HOME=/usr/lib/jvm/java-25-openjdk ALSOFT_DRIVERS=null xvfb-run -a \
  ./gradlew :fabric:26.2:runClientGameTest \
  -Pfabric.clientTests=true -Pfabric.mediaTests=true
```

В этом же прогоне сохраняются изображения стандартных углублённых портов,
GPS-базы и минималистичного машинного интерфейса.
