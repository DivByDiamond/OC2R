## Renderer changes

- `255a69f` fixes enchanted/glint rendering during projector depth rendering by
  using dedicated fixed buffers for vanilla render layers. `c141d4b` restores
  depth writes after weather rendering. These changes concern the older
  immediate OpenGL renderer. OC2R's Minecraft 26.x projector has a separate
  frame-graph implementation, so these are regression scenarios rather than
  patches to copy into the Fabric 26.x port.
- `d165f92` derives terminal visibility/camera offset from the pose stack,
  allowing rendering on moving constructions. Compare against both the local
  1.21.1 renderer and 26.x extracted render states; the APIs differ.
- `6ec36bf` namespaces extension methods to prevent clashes with other mods.
  OC2R already uses namespaced accessors in its modern projector pipeline;
  inspect any remaining legacy extension methods independently.

## Dependencies, guest APIs and optional integration

- `7f8f1c6` raises Sedna from **5.2.0 to 5.3.0** and sedna-cpm from **0.3.0 to
  0.4.0**. OC2R still uses Sedna 5.2.0 and has no sedna-cpm dependency. Keep an
  emulator upgrade separate from the Fabric port so snapshot and guest-boot
  regressions have a clear cause.
- `3466840` adds substantial RISC-V/Z80, HLAPI/MLAPI and serial protocol
  documentation, plus blob-channel and guest library adjustments. `2fdf693`
  corrects Z80/MLAPI naming. OC2R does not currently provide this MLAPI/blob
  transport, so these are reference material for its planned driver layer and
  Z80 work, not directly applicable fixes to its existing RPC API.
- `820e1c4` supplies Sable's `silent_assembly_removal` block tag. Treat it as an
  optional integration candidate after lifecycle verification, not evidence
  that every OC2R/loader/version combination supports Sable.
- `6b5fb78` is a small upstream PMD cleanup and does not justify an independent
  OC2R behavior change.
