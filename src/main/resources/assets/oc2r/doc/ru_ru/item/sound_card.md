# Звуковая карта
![Меньше звука тишины](item:oc2r:sound_card)

Звуковая карта позволяет проигрывать разные звуковые эффекты из своей огромной библиотеки реалистичных семплов. Из-за некоторых технических особенностей, последовательное проигрывание эффектов требует небольшой паузы между ними. Если попытаться проиграть эффект в это время, то звука просто не будет.

Это высокоуровневое устройство, поэтому оно контролируется через высокоуровневое API (HLAPI). Дистрибутив Linux предоставляет Lua библиотеку для данного API. Например:  
`local d = require("devices")`  
`local s = d:find("sound")`  
`s:playSound("entity.creeper.primed")`

## API
Название устройства: `sound`

### Методы
`playSound(name:string[,volume:float,pitch:float])` проигрывает звуковой эффект с указанным именем.
- `name` - название эффекта для проигрывания.
- `volume` - громкость проигрывания эффекта в диапазоне от `0` до `1`, где `1` - нормальная громкость. Опционально, по умолчанию `1`.
- `pitch` - высота звука для проигрываемого эффекта в диапазоне от `0.5` до `2`, где `1` - нормальная высота. Опционально, по умолчанию `1`.
- Создает ошибку, если такого эффекта не существует.

`findSound(name:string):table` возвращает список доступных звуковых эффектов с таким именем. Учитывайте, что количество выдаваемых результатов ограничено, поэтому запросы с большим количеством результатов будут обрезаться.
- `name` - название звукового эффекта для поиска.
- Возвращает список названий звуковых эффектов по указанному запросу.

## Тоны и PCM

*beep(frequency:number,duration:number)* воспроизводит тон от 20 до 20000 Гц длительностью от 20 до 5000 миллисекунд. *playTone* — другое имя того же метода. Пример: *s:beep(880, 500)*.

*write(data:table)* принимает массив числовых значений байтов: знаковый 16-битный PCM, little-endian, один канал, 44100 Гц. Один отсчёт занимает два байта. RPC передаёт массив JSON, а не бинарную строку Lua. Отправляйте небольшие порции с паузами: действует настраиваемый лимит карты, по умолчанию 131072 байта в секунду. Реальная скорость RPC может быть значительно ниже скорости звука. Метод не декодирует MP3 или WAV: нужны готовые PCM-данные без заголовка контейнера.

## Воспроизведение музыки

Сырой PCM через RPC требует 88200 чисел в секунду, что гость не успевает отправлять в реальном времени. Поэтому музыку проигрывают как **DFPWM**: формат с одним битом на отсчёт, нужно всего 6 КБ/с (его используют динамики ComputerCraft).

*writeDfpwm(data:table[,sampleRate:number]):boolean* декодирует порцию и ставит её в очередь. *data* — массив байтов не длиннее 8192, младший бит первым. *sampleRate* — частота, с которой записан файл, от 8000 до 48000, по умолчанию 48000; динамик сам приводит звук к своим 44100 Гц. Состояние декодера переходит из порции в порцию, поэтому файл режьте на части и отправляйте по порядку.

Вызов возвращает *false* и ничего не принимает, если в очереди уже около двух секунд звука. *getBufferedMs():number* возвращает, сколько звука стоит в очереди перед позицией воспроизведения. Подождите и отправьте ту же порцию снова, например `while not s:writeDfpwm(chunk) do os.execute("sleep 0.2") end`. Сырой PCM *write* подчиняется тому же правилу и тоже возвращает *true* или *false*. После секунды тишины следующая запись начинает новый поток.

Любой аудиофайл конвертируйте на своём ПК через ffmpeg, а в гостя переносите [картой импорта/экспорта файлов](../item/file_import_export_card.md) или дискетой:

*ffmpeg -i song.mp3 -ac 1 -ar 48000 -f dfpwm song.dfpwm*

В стандартном образе Linux есть проигрыватель: *play.lua song.dfpwm* (или *play.lua -r 32000 song.dfpwm* для файла с другой частотой).

*findSound* возвращает не больше 25 совпадений. Пауза между игровыми эффектами относится к *playSound*. Для внешнего устройства с тонами и PCM используйте [динамик](../block/speaker.md).
