# Карта импорта и экспорта файлов
![Между гостем и игроком](item:oc2r:file_import_export_card)

RPC-устройство *file_import_export* передаёт файлы между гостевой ОС и игроками, которые сейчас используют терминал. При загрузке принимается ответ первого игрока; сохранение скачанного файла предлагается всем текущим пользователям терминала. Без пользователей запрос импорта возвращает false.

Старые скрипты *import.lua* и *export.lua* в текущий пакет не входят. Используйте API из своей гостевой программы или добавьте собственные обёртки. Настройка Lua описана в разделе [скрипты](../scripting.md).

## API

*beginExportFile(name)* начинает экспорт, *writeExportFile(data)* добавляет массив числовых значений байтов, *finishExportFile()* открывает диалоги сохранения у игроков. Максимальный размер экспорта — 1048575 байт.

*requestImportFile():boolean* открывает диалог загрузки. Вызывайте *beginImportFile()* до получения метаданных *name* и *size*, затем читайте *readImportFile()*: каждый вызов возвращает массив байтов, пустой массив означает конец. Отмена вызывает ошибку. Соблюдайте порядок вызовов; одновременно выполняется только одна передача.
