# Дискета
![Лучше не гните ее](item:oc2r:floppy)

Дискета является сменным носителем. Это значит, что их можно менять в [дисководе](../block/media_station.md) не перезагружая [компьютер](../block/computer.md).

Загляните в раздел по [дисководу](../block/media_station.md), в нем содержатся полезные команды для работы с дискетами в Linux.
