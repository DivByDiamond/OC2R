# Модуль крафта
![Создаём вещи](item:oc2r:crafting_module)

Позволяет [роботу](robot.md) создавать предметы по рецептам. Устройство HLAPI называется *crafting*.

В Lua: *local c = require("devices"):find("crafting")*, затем *c:craft()*.

Верхние девять слотов инвентаря робота, с номерами от 0 до 8, образуют сетку 3 на 3. Результат помещается в нижний ряд, начиная с выбранного слота. Нумерация слотов API начинается с нуля.

*craft():number* выполняет один крафт. Возвращает число созданных предметов или 0, если подходящего рецепта нет либо в нижнем ряду не хватает места. Остатки ингредиентов, например вёдра, обрабатываются отдельно от результата.
