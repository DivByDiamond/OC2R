# Видеокарта
![GPU](item:oc2r:gpu_tier_1)

Установите видеокарту в слот GPU компьютера перед загрузкой, чтобы использовать подключённые [мониторы](../block/monitor.md). Без GPU монитор не создаёт устройство кадрового буфера и остаётся тёмным. Собственный текстовый терминал компьютера работает и без видеокарты.

Четыре уровня GPU обеспечивают разрешения 320 на 200, 640 на 400, 1024 на 768 и 1920 на 1080 пикселей. Монитор использует разрешение установленной видеокарты, а не постоянное 640 на 480. Чем больше изображение, тем больше требуется ресурсов и пропускной способности. [Проектор](../block/projector.md) — отдельное устройство 640 на 480.

Выключайте компьютер перед заменой GPU. Экрану по-прежнему нужны соединение с шиной и питание: видеокарта не питает его сама.
