# Жёсткий диск
![Хранилище данных](item:oc2r:hard_drive_large)

Жёсткие диски добавляют постоянное хранилище [компьютерам](../block/computer.md) и [роботам](robot.md). У стандартного Linux уже есть встроенный записываемый корневой диск, поэтому дополнительный жёсткий диск необязателен. Изменения встроенного диска сохраняются вместе с виртуальной машиной отдельно от съёмных накопителей.

Дополнительные диски появляются в Linux как блочные устройства, например */dev/vdb*. Буква зависит от подключённых устройств: перед форматированием проверьте */proc/partitions*. Для нового диска создайте файловую систему, каталог и точку монтирования; пример команд есть на странице [дисковода](../block/disk_drive.md). Форматирование уничтожает данные. Не форматируйте встроенный корневой диск вместо дополнительного.

Рецепт диска OnyxOS использует жёсткий диск среднего уровня. Это отдельный вариант, не требующийся стандартному Linux. У собственных образов ОС могут быть другие требования к дискам.

Выключайте компьютер перед установкой и извлечением диска. Сохраняйте исходный предмет, чтобы сохранить его данные.
