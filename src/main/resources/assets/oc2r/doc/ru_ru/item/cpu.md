# Процессор
![CPU](item:oc2r:cpu_tier_1)

Процессор необходим для запуска компьютера или робота. Установите его в слот CPU при выключенном устройстве. Сейчас используется одноядерная 64-битная архитектура RISC-V с поддержкой чисел с плавающей запятой. Lua — программа внутри гостевой ОС, а не отдельная архитектура процессора.

Четыре обычных уровня по умолчанию работают на 50, 100, 200 и 400 МГц. Частота задаётся при регистрации предмета; назначенное значение указано в его названии. В конфигурации сервера предусмотрены настройки уровней. У творческого процессора отдельная частота 1 ГГц. Заданная частота эмуляции не гарантирует соответствующую скорость на любом реальном компьютере.

Быстрый процессор не заменяет [ОЗУ](memory.md), прошивку и питание. См. [первый запуск](../getting_started.md).
