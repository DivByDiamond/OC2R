# Модуль сканера
![Осмотр мира](item:oc2r:scanner_module)

Позволяет [роботу](robot.md) исследовать блоки, жидкости и сущности. Устройство HLAPI называется *scanner*. В Lua: *local s = require("devices"):find("scanner")*.

## Методы

*inspect(side):table* исследует соседнюю ячейку со стороны *front*, *up* или *down*. Возвращает поля *block*, *fluid* при их наличии и список *entities*. Жидкости обозначаются идентификатором исходной жидкости, например *minecraft:water*.

*scan():table* сканирует куб 7 на 7 на 7 блоков с роботом в центре. Возвращает *hardness* и *entities*. Повторное сканирование доступно через 5 секунд игрового времени; ранний вызов вызывает ошибку.

*hardness* — Lua-таблица из 343 чисел от 0 до 255, а не строка. Оси мировые: X на восток, Y вверх, Z на юг. Перебор идёт по Y, затем Z, затем X от -3 до 3. Индекс Lua для смещения x, y, z: `(y + 3) * 49 + (z + 3) * 7 + (x + 3) + 1`. Значение 0 означает воздух, 254 — жидкость, 255 — неразрушаемый или недоступный блок, 1–253 кодируют твёрдость обычного блока. Список сущностей содержит до 20 идентификаторов, ближайшие идут первыми.

*getScanLayer(layer:number):table* возвращает 49 чисел из последнего сканирования. Номер слоя от 0 до 6, снизу вверх. Без выполненного сканирования вызов вызывает ошибку.

*canSeeSky():boolean* проверяет доступность неба в ячейке робота.
