# Флеш-память и прошивка
![Загрузочный код](item:oc2r:flash_memory)

Микросхема содержит начальный код, который выполняет [компьютер](../block/computer.md) или [робот](robot.md) при включении. Пустая флеш-память и микросхема с готовой прошивкой — разные предметы. Одна пустая микросхема не обеспечивает загрузку ОС.

Стандартная прошивка Linux представляет собой небольшой загрузочный ROM и читает ядро со встроенного корневого диска. Ядро больше не находится внутри этой прошивки. Для обычного запуска Linux отдельный жёсткий диск не нужен.

Чтобы получить прошивку крафтом, соедините самую вместительную пустую флеш-память с [ключом](wrench.md): получится прошивка Linux. Повторный крафт полученной микросхемы Linux с ключом даёт прошивку OnyxOS. Ключ возвращается. Не путайте эти рецепты с очисткой прошивки.

[Программатор](../block/flash_memory_flasher.md) также позволяет выбрать встроенную прошивку или загрузить локальный образ через интерфейс. Выключайте компьютер перед заменой микросхемы. У собственной прошивки могут быть другие требования к загрузке и дискам.
