# GPS-башня
![GPS-башня](block:oc2r:gps_tower)

Башня сообщает положение своего основания и измерение. В режиме относительных координат можно объединить несколько башен в радиосеть и получать смещения от выбранной главной башни.

Для установки нужны прочное основание и пять свободных блоков по высоте. Подключите основание к компьютеру через интерфейсную шину. Имя устройства: `gps_tower`.

## Обычный режим

```lua
local gps = assert(require("devices"):find("gps_tower"))
local p = gps:getPosition()
print(p[1], p[2], p[3])
print(gps:getDimension())
```

По умолчанию возвращаются мировые X, Y, Z основания. Повреждённая башня вызывает ошибку. `isAssembled()` проверяет целостность.

## Относительный режим

В общем конфиге OC2R параметр `gameplay.relative_coordinates` включает относительные координаты. Параметр `gameplay.gps_tower_range` задаёт дальность между соседними башнями, по умолчанию 45 блоков по горизонтали. Покрытие круглое по X/Z, высота не ограничивает связь. Между измерениями связи нет.

На первой башне вызовите `setAsReference()`, затем прочитайте `getNetworkId()`. На следующих башнях вызовите `joinNetwork(id)`, передав этот ID. В сети может быть только одна главная башня. Её позиция равна `(0, 0, 0)`.

`hasSignal()` сообщает, есть ли путь до главной. Если пути нет, `getPosition()` вызывает ошибку и не возвращает мировые XYZ. Чужие сети не участвуют в передаче. Башни в выгруженных чанках продолжают работать по сохранённой схеме. При разрушении узел удаляется.

Чтобы назначить другую главную, сначала вызовите `clearReference()` на прежней. Такая смена меняет начало координат, поэтому сохранённые точки нужно обновить.

Башня не определяет позицию игрока и не добавляет GPS-приёмник роботу. У [робота](../item/robot.md) остаются собственные локальные координаты.

[Полная инструкция и методы](https://wiki.loki-code.dev/ru/reference/gps-networks).
