# Программатор
![Запись прошивки](block:oc2r:flash_memory_flasher)

Используйте микросхему флеш-памяти или записываемый жёсткий диск на программаторе, чтобы вставить носитель. Обычный клик пустой рукой открывает окно записи. Клик пустой рукой с приседанием извлекает носитель, если запись не выполняется.

В интерфейсе можно выбрать встроенную прошивку или загрузить локальный образ. Сервер проверяет тип и вместимость носителя. Запись заменяет прежнее содержимое: дождитесь её завершения. Окно записи не начинает операцию, если программатор смонтирован работающим компьютером; сначала выключите этот компьютер.

При подключении через шину программатор также предоставляет вставленный записываемый носитель гостевой ОС как блочное устройство, например */dev/vdb*. Найдите нужное устройство в */proc/partitions*. Сырой образ можно записать стандартными инструментами гостевой ОС, но ошибка в выборе устройства уничтожит данные. Старый скрипт *flash.sh* в текущий пакет скриптов не входит.

О готовых прошивках и загрузке см. [флеш-память](../item/flash_memory.md).
