# Медиастанция
![Медиастанция](block:oc2r:media_station)

Медиастанция объединяет дисковод и программатор. Верхнее гнездо принимает дискету, нижнее — флеш-память или HDD. Оба носителя подключаются к компьютеру через один задний порт шины как два независимых блочных устройства.

Вставляйте носитель предметом в руке. Shift + ПКМ по верхней половине извлекает дискету, по нижней — флеш-память или HDD. Обычный ПКМ открывает окно записи прошивки или образа. Запись блокирует нижнее гнездо; если носитель смонтирован работающим компьютером, сначала выключите компьютер.

Перед извлечением носителя размонтируйте его в гостевой ОС. Найти устройства можно в */proc/partitions*. Старые дисковод и программатор удалены; для обоих действий используется медиастанция.
