# Интернет-шлюз
![Выход из локальной сети](block:oc2r:internet_gateway)

Шлюз предоставляет кабельной сети доступ к интернет-адаптеру реального сервера. Используйте сетевые разъёмы и сетевые кабели, а не шину устройств. Интернет должен быть включён администратором; ограничения адресов и соединений продолжают действовать.

Шлюз передаёт Ethernet-кадры и не является автоматическим DHCP-сервером. Требования соединения «точка-точка» описаны у [интернет-карты](../item/internet_card.md), настройка локальной сети — в разделе [сети](../networking.md).
