# Сетевой коммутатор
![Запоминает, где находятся хосты](block:oc2r:network_switch)

Сетевой коммутатор соединяет до шести [сетевых разъемов](network_connector.md), по одному на каждой грани. Он запоминает, с какой грани в последний раз пришел отправитель пакета, и пересылает пакет, адресованный этому отправителю, только туда. Пакет для еще не встречавшегося адреса отправляется на все остальные грани. Этим он отличается от [сетевого концентратора](network_hub.md), который повторяет каждый пакет везде. Каждый шаг пересылки уменьшает время жизни пакета на один переход.

Адреса забываются после двух минут без трафика. Пакет не возвращается на ту грань, с которой пришел, если для нее не включен hairpin.

Если к коммутатору прилегает [шинный кабель](bus_cable.md), он также является устройством на шине устройств с именем типа `switch` и методами:

- `getHostTable()` возвращает известные хосты: MAC-адрес, возраст записи в тиках и грань.
- `getLinkState()` возвращает для каждой грани, подключен ли к ней разъем или другое сетевое устройство.
- `getPortConfig()` возвращает настройки каждой грани.
- `setPortConfig(settings)` заменяет их. Настройка содержит `untagged` (VLAN пакетов без метки, 0 — нет), `tagged` (VLAN, проходящие с меткой), `hairpin` и `trunkAll` (пропускать все VLAN с меткой).

Грани нумеруются: вниз, вверх, север, юг, запад, восток.
