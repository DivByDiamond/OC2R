# Первый запуск

Вам понадобятся [компьютер](block/computer.md), один [процессор](item/cpu.md) и четыре модуля [ОЗУ](item/memory.md) по 8 МиБ. Итого 32 МиБ — удобная начальная конфигурация. Компьютер из обычного рецепта уже содержит [прошивку Linux](item/flash_memory.md). В пустой компьютер, полученный другим способом, её может потребоваться установить отдельно.

Поставьте компьютер и откройте его инвентарь [ключом](item/wrench.md). Установите процессор, память и прошивку в соответствующие слоты. Готовый компьютер из творческого режима уже содержит компоненты. Подведите энергию: подсказка полоски питания показывает запас и расход. Откройте терминал, нажмите кнопку питания, дождитесь приглашения входа и введите *root*.

Стандартный Linux загружается со встроенной записываемой корневой файловой системы. Отдельный жёсткий диск и старый рецепт «Linux-диск + ключ» для запуска не нужны. Дополнительные [жёсткие диски](item/hard_drive.md) служат для данных; форматирование стирает их содержимое. Прошивка загружает ядро со встроенного корневого диска.

Встроенный терминал компьютера работает без видеокарты. Для [монитора](block/monitor.md) установите [GPU](item/gpu.md), соедините монитор с компьютером [интерфейсами](block/bus_interface.md) и [шинными кабелями](block/bus_cable.md), а также подайте питание на экран. [Проектор](block/projector.md) — отдельное устройство с фиксированным разрешением.

Выключайте компьютер перед заменой нативных компонентов. При ошибке запуска проверьте процессор, ОЗУ, прошивку, питание и сообщение в терминале. Настройки сервера могут изменять характеристики компонентов и расход энергии.

Далее читайте [основы](basics.md), [скрипты](scripting.md), [сети](networking.md) и [робототехнику](robotics.md).
