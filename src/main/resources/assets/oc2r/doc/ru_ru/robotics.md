# Робототехника

[Робот](item/robot.md) — мобильный компьютер. Установите процессор, ОЗУ и прошивку, зарядите его на [заряднике](block/charger.md) и включите через терминал. Вместо карт он использует модули и не подключается к внешней шине устройств.

Подготовьте Lua, как описано в разделе [скрипты](scripting.md), затем выполните:

```lua
r = require("robot")
print(r.move("forward"))
print(r.turn("left"))
```

Эти функции библиотеки ожидают завершения и возвращают результат. Прямые вызовы через *devices* только ставят действия в очередь: успешная постановка ещё не означает завершённое перемещение.

Нумерация слотов инвентаря начинается с нуля. Для переноса предметов нужен [модуль управления инвентарём](item/inventory_operations_module.md), для разрушения и установки блоков — [модуль операций с блоками](item/block_operations_module.md), для рецептов — [модуль крафта](item/crafting_module.md), для исследования мира — [сканер](item/scanner_module.md).

*r.facing()* возвращает сторону света. *r.position()* сообщает положение относительно места установки или последней калибровки; *r.calibrate()* сбрасывает начало координат. Это не абсолютные мировые координаты и не GPS. Подробности асинхронных действий и остальных методов есть на странице [API робота](item/robot.md).
