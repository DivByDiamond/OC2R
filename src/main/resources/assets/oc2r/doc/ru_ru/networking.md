# Сети

Соедините [сетевые разъёмы](block/network_connector.md) [сетевыми кабелями](item/network_cable.md) и установите [сетевую карту](item/network_interface_card.md) в каждый компьютер. Разъёмы крепятся к любой стороне компьютера, кроме передней. В настройках карты можно разрешать и запрещать отдельные стороны.

Разъёмы передают кадры между кабельными соединениями. Для разветвлений используйте [концентратор](block/network_hub.md). Избегайте замкнутых контуров: лимит переходов останавливает бесконечную пересылку, но до его исчерпания возможны дубликаты кадров.

## Настройка Linux

Выключите компьютер перед установкой карты, затем загрузите Linux. Узнайте имя интерфейса в оболочке:

```sh
ifconfig -a
```

Для локальной сети из двух компьютеров выполните на первом, заменив `eth0` при необходимости:

```sh
ifconfig eth0 192.168.50.1 netmask 255.255.255.0 up
```

На втором компьютере:

```sh
ifconfig eth0 192.168.50.2 netmask 255.255.255.0 up
```

Проверьте связь с первого компьютера:

```sh
ping 192.168.50.2
```

Это временные настройки; постоянные задаются конфигурацией сети гостевого Linux.

Старый мастер *setup-network.lua* в текущий комплект скриптов не входит. Кабель и концентратор сами не являются DHCP-серверами. Клиент *udhcpc -i eth0* получает адрес только при наличии настоящего DHCP-сервера в сети. Не запускайте несколько серверов DHCP и не смешивайте статические адреса с диапазоном автоматической выдачи.

В гостевой системе есть клиенты *ssh* и *scp*. Для удалённого входа на принимающем компьютере нужен работающий SSH-сервер. Для собственных сетевых программ доступна LuaSocket. [Интернет-карта](item/internet_card.md) использует отдельное соединение через реальный сервер и не настраивается как локальная сеть с DHCP.
