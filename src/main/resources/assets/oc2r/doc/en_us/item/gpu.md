# GPU
![Graphics card](item:oc2r:gpu_tier_1)

Install a GPU in a computer's GPU slot before booting to enable its connected [monitors](../block/monitor.md). Without a GPU, a monitor has no framebuffer device and stays dark. The computer's own text terminal still works.

The four GPU tiers provide 320 by 200, 640 by 400, 1024 by 768 and 1920 by 1080 pixels. A monitor uses the installed GPU's resolution, not a fixed 640 by 480 image. Larger images require more resources and bandwidth. The [projector](../block/projector.md) is a separate 640 by 480 device.

Shut down before changing the GPU. The display still needs a bus connection and energy; a GPU alone does not power it.
