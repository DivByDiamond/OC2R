# Floppy
![It's not the floppy that bends](item:oc2r:floppy)

Floppy disks are removable media. This means they can be inserted and removed from [disk drives](../block/media_station.md) without the [computer](../block/computer.md) using the disk drive having to reboot to use them.

Please see the [disk drive](../block/media_station.md) manual entry for some useful commands when working with floppies.
