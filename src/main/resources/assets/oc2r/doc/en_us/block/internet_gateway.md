# Internet Gateway
![Network exit](block:oc2r:internet_gateway)

The gateway exposes the host-backed Internet adapter to the device network. Connect it with network connectors and cables, not a device-bus cable. Internet access must be enabled by the server administrator, and destination/session restrictions still apply.

It forwards Ethernet frames; it is not an automatic DHCP server. See the [Internet card](../item/internet_card.md) for point-to-point setup requirements and [networking](../networking.md) for local network setup.
